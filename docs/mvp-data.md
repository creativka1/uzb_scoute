## Что отсутствует

У всех десяти отсутствуют подтверждённая точная позиция, ведущая нога, контракт и продвижение мяча. Зарплаты не используются. Имеющиеся `public/players/*` изображения не привязаны к этим ID: в MVP используются инициалы, без внешних запросов фотографий. Полное покрытие сезона 2025 не подтверждено. Данные 2026 и матчи других лиг не подставляются вместо выбранного периода.

## Источники и расчёты

- Исходный SofaScore cache в `data/cache` оставлен без изменений.
- API читает `data/superliga_stats.json`, `data/metric_observations.json.gz`, `data/audits/data_integrity.json` и `data/detailed_positions.json`.
- `/api/mvp/players` возвращает ровно фиксированную десятку. Старые `/api/players` и `/api/analysis` сохранены для расширенной работы, но основной UI не загружает матч-центр.
- `lib/mvp-data.ts` вызывает существующий API в процессе сервера: запросы к провайдерам не нужны.
- Scout Index и радар используют прежние сравнения по всей лиге и позиции, с учётом покрытия минут. Исходные null сохраняются.
- Подбор использует `rankPlayersForNeed()` для соответствия позиции/периода и исключения своего клуба, затем сортирует по существующему Scout Index. Новый fit score не выдаётся за Scout Index.
- Similarity Index сохранён из `getSimilarPlayers()`; это расстояние между ролевыми профилями, не оценка успешности трансфера.
- xG/xA за 90 минут берутся из наблюдений с покрытыми минутами, не делятся на все минуты выборки.

Репозиторий не обновлял данные через сеть при разработке MVP. Ни новые API, ни CV, ни синтетическая футбольная статистика не добавлены.
