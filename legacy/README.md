# Сохранённый интерфейс

`dashboard.tsx` и `dashboard.css` — прежний расширенный интерфейс. Они не являются маршрутами Next.js и не импортируются MVP. Компоненты матч-центра и расширенного анализа в `components/football`, расчёты в `lib`, прежние API и кэш оставлены для будущей работы. `components/SkillRadar.tsx`, `components/ShotMap.tsx` и `types/scouting.ts` также не входят в граф импортов MVP; их прежние шкалы и заглушки не используются новым интерфейсом.
