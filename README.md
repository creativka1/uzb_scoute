# Uzstat — scouting MVP

Аналитическая платформа для поиска и сравнения футболистов. Основной сценарий: команда / потребность → подбор → профиль игрока → избранное → сравнение двух игроков.

## Что входит

- Главная с тремя действиями и десятью игроками.
- Игроки: поиск по имени, команда, максимальный возраст и стоимость; сброс восстанавливает полный список.
- Подбор: позиция, максимальный возраст и стоимость, минимум минут. Кандидаты сортируются по существующему Scout Index. При переходе из команды исключаются её игроки.
- Профиль: восемь доступных метрик, покрытие матчей, Scout Index, сильные стороны, один радар и Similarity Index.
- Команды: только клубы выборки и представленные игроки, без матч-центра.
- Избранное: добавление, удаление, восстановление после обновления страницы, выбор двух игроков для сравнения. Хранение в localStorage; повреждённый список не перезаписывается. Старые сохранения мигрируют по ID, игроки вне MVP остаются сохранёнными.
- Сравнение двух игроков на общей шкале, без синтетического «среднего игрока».

Весь интерфейс на русском; имена игроков и клубов сохранены в написании источника. На мобильном экране вместо широкой таблицы используются компактные карточки.

## Запуск

Node.js 22 и Python 3.11+. Не нужны база данных, ключи API или обновление кэша.

```bash
npm ci
npm run dev
```

Для проверки production:

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm run start
```

`lint` в существующем проекте запускает TypeScript-проверку; отдельного ESLint-конфига нет.

Браузерные проверки основного сценария, localStorage, фильтров, всех профилей и мобильной/настольной вёрстки:

```bash
npx playwright install chromium
npm run build
npm run test:e2e
```

Если Chromium уже установлен в системе:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

Playwright автоматически запускает отдельный production-сервер на порту 3100; этот порт должен быть свободен. Существующий сервер не переиспользуется, чтобы проверки не работали со старой сборкой. Не запускайте dev и production одновременно с одной папкой `.next`.

## Данные

MVP показывает ровно 10 реальных полузащитников Узбекистана с пятью доступными ролевыми осями и наибольшим числом подтверждённых минут в сезоне 2025. Подтверждённых вингеров в текущих профильных данных нет; точные позиции не выдумываются. Список, доступные метрики и покрытие каждого игрока: [docs/mvp-data.md](docs/mvp-data.md).

Старый кэш и исходный API сохранены. Рейтинги вычисляются прежней системой относительно всей лиги/позиции, не только десяти игроков MVP. `null` показывается как «—», реальный ноль сохраняется. Частичные метрики используют только покрытые матчи и минуты. Полный сезон не подтверждён; клуб и стоимость могут относиться к более позднему профилю.

У выбранных игроков отсутствуют контракт, ведущая нога, точная позиция и продвижение мяча. Реальные фото сохранены по существующим SofaScore ID в `public/players/sofascore/`; источник и контрольные суммы указаны в `manifest.json`. Если фото недоступно, показывается нейтральный placeholder с инициалами. Новые API-запросы и обновление статистики для запуска не требуются.

## Маршруты

`/`, `/players`, `/players/[id]`, `/teams`, `/teams/[id]`, `/recruitment`, `/shortlist`, `/compare`.

`/api/mvp/players` — только десять игроков MVP. Старые `/api/players` и `/api/analysis` оставлены для будущих задач.

## Сохранённые эксперименты

- Прежний экран и стили: `legacy/dashboard.tsx`, `legacy/dashboard.css`.
- Прежняя документация: `legacy/previous-readme.md`.
- Видеоэксперимент: `experiments/video-tracking/track.ipynb`; не импортируется приложением и не нужен сборке.
- Матч-центр, расширенные роли, доска решений и аналитические компоненты оставлены в `components/football`, `lib` и `scripts`, но не импортируются страницами MVP.
- Неиспользуемые прежние `SkillRadar`, `ShotMap` и `types/scouting` не входят в MVP. Их заглушки не используются новым радаром.

SofaScore cache/sync сохранён. Никакие данные, тестовые фикстуры провайдера или notebook outputs не загружаются в UI как новые футбольные факты. Платные API и видеоанализ не подключаются.
