# UzStat Talent Tracker 🇺🇿⚽

Интерактивный веб-дашборд футбольного скаутинга и аналитики молодых талантов Суперлиги Узбекистана (U21).

## Стек технологий
- **Фреймворк:** Next.js 15 (App Router, React 19, TypeScript)
- **Стилизация:** Tailwind CSS v4
- **Графика и визуализация:** Recharts (радарные диаграммы навыков) + кастомный SVG-компонент футбольного поля (Shot Map)
- **Иконки:** Lucide React

## Быстрый запуск
1. Распакуйте архив
2. В терминале в папке проекта выполните:
```bash
npm install
npm run dev
```
3. Откройте в браузере: `http://localhost:3000`

## Автоматическое обновление данных

GitHub Actions ежедневно обновляет профильные данные игроков через SofaScore API:
- текущий клуб;
- трансферную стоимость;
- дату окончания контракта;
- гражданство;
- номер;
- предпочитаемую ногу;
- рост.

Workflow также можно запустить вручную в GitHub: **Actions → Refresh player profiles → Run workflow**.

После обновления изменённый `data/superliga_stats.json` автоматически коммитится в репозиторий. Если проект развёрнут из GitHub (например, через Vercel), новый коммит также запускает новое развёртывание.
