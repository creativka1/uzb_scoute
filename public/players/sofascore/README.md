# Фотографии игроков

Фото сохранены с существующих URL `photoUrl` для десяти игроков MVP. ID в именах файлов — их реальные SofaScore ID. `manifest.json` содержит исходные URL и SHA-256 файлов. JPEG и WebP сохранены без изменения содержимого.

Интерфейс использует эти локальные изображения и показывает нейтральный placeholder, если изображение недоступно. Файлы `public/players/1.png`–`5.png` не привязаны к подтверждённым игрокам и здесь не используются.
